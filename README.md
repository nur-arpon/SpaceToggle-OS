# SpaceToggle OS 🚀 — V11.0 Flat Matrix Framework

> **SPACE + INITIAL of your desired app = BOOM! It opens. Press the same combination again... BOOM! It closes.**[cite: 1]

SpaceToggle OS is a lightning-fast, minimalist window manager for Windows, powered by the high-performance AutoHotkey v2 runtime layer[cite: 1]. SpaceToggle transforms your ordinary Spacebar into an intelligent hyper-modifier[cite: 1]. Hold Spacebar and tap a letter to instantly summon or banish your most-used applications in zero milliseconds[cite: 1].

---

## 🚀 The Core Matrix (V11.0) One-Liner

We have upgraded to a hardened, flat deployment engine[cite: 2]. This single command prepares your environment, terminates stale background tasks, compiles the active glass engine layers, and hooks native system startup pipelines[cite: 2].

```powershell
irm [https://raw.githubusercontent.com/nur-arpon/SpaceToggle-OS/main/install.v.11.ps1](https://raw.githubusercontent.com/nur-arpon/SpaceToggle-OS/main/install.v.11.ps1) | iex
```

## 🛠️ How to Install in 10 Seconds

1. Click on the **Windows Search Bar**, type **PowerShell**, right-click it, and select **Run as Administrator**[cite: 1].
2. Copy the single-line installation command from above[cite: 1].
3. Paste it directly into your terminal and hit **ENTER**[cite: 1]. The automation matrix handles the rest[cite: 1].

## 🔄 Core Navigation & System Layer Modifiers

* **Profile Switching:** Hold **` Space `** and tap **` Right Alt `** to switch between layout workflows dynamically[cite: 2].
* **Secure Boss Key Sweep:** Hold **` Space `** and tap **` Esc `** to immediately hide all open app panels from display[cite: 2]. Tap again to restore them[cite: 2].
* **Multi-Corner Fluid PiP:** Hold **` Space `** and tap **` ` `** (Backtick) to transition any window into an always-on-top Picture-in-Picture layout cycling through four corner coordinates[cite: 2].
* **Smart Field Auto-Focus:** Hold **` Space `** and tap **` , `** (Comma) to contextually lock target focus straight into app input forms or search areas[cite: 2].
* **Dynamic Glass Opacity:** Hold **` Space `** and scroll your **` Mouse Wheel Up / Down `** to fluidly alter window frame alpha transparencies[cite: 2].
* **Double-Tap Rapid Scroll:** Hold **` Space `** and quickly double-tap **` Up Arrow `** or **` Down Arrow `** to instantly jump directly to the top or bottom boundaries of long documents and web pages[cite: 2].

* **Liquid Glass Style Engine:** Directly taps into the Windows 11 Desktop Window Manager (DWM) API, rendering beautiful 25% opacity Acrylic sheets, sleek border parameters, and modern rounded windows[cite: 2].
