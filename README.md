# SpaceToggle OS 🚀

> **SPACE + INITIAL of your desired app = BOOM! It opens. Press the same combination again... BOOM! It closes.**

SpaceToggle OS is a lightning-fast, minimalist window manager for Windows, powered by the high-performance AutoHotkey v2 runtime layer. Stop Alt-Tabbing through 20 open windows. SpaceToggle transforms your ordinary Spacebar into an intelligent hyper-modifier. Hold Spacebar and tap a letter to instantly summon or banish your most-used applications in zero milliseconds.

---

## 🚀 The Ultimate Engine (V5.0.0) One-Liner

We have unified all operational profiles into a single, automated, hardware-adaptive deployment engine. This single command checks your system architecture, builds your local environment, installs your dynamic runtime profiles, and establishes a secure two-way sync with your cloud repository.

```powershell
irm https://raw.githubusercontent.com/nur-arpon/SpaceToggle-OS/main/install-v5.0.ps1 | iex
```

---

## 🛠️ How to Install in 10 Seconds

1. Click on the **Windows Search Bar**, type **PowerShell**, right-click it, and select **Run as Administrator**.
2. Copy the single-line installation command from above.
3. Paste it directly into your terminal and hit **ENTER**. The automation matrix handles the rest.

## ✨ Core Features

* **Zero-Latency Toggling:** Instantly show, hide, or launch your applications without ever touching your mouse or checking your taskbar.
* **Smart Window Detection:** If an app is closed, the engine launches it. If it is open but buried under 10 background windows, it pulls it directly to the absolute front of your focus. If it is already focused on top, it instantly minimizes it out of your way.
* **Non-Intrusive Engine Hooking:** Your Spacebar functions perfectly for normal typing, text entry, and system operations. No typing friction, no dropped inputs.
* **Zero Disk I/O Boot Path Scanner:** Scans and caches your local machine application installation paths entirely on bootup, executing app calls with zero hard drive lag.
* **Hardware-Adaptive Resource Management:** Intelligently checks system configurations. Operates at a "High Priority" execution tier on powerful machines, and triggers a lightweight, background memory optimization loop on lighter rigs.
* **Fail-Safe Error Guarding:** Traps operational system faults silently and logs them locally to `faultsV5.log` rather than throwing disruptive Windows dialog crashes.
* **Automated Cloud Sync:** Features built-in automatic two-way git integration that pushes your local profile iterations instantly back to your repository on installation.
