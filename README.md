# SpaceToggle OS 🚀

> **SPACE + INITIAL of your desired app = BOOM!** It opens. Press the same combination again... **BOOM!** It closes. 

SpaceToggle OS is a lightning-fast, minimalist window manager for Windows, powered by the high-performance AutoHotkey v2 runtime layer. Stop Alt-Tabbing through 20 open windows. SpaceToggle transforms your ordinary Spacebar into an intelligent hyper-modifier. Hold Spacebar and tap a letter to instantly summon or banish your most-used applications in zero milliseconds.

## 🛠️ How to Install in 10 Seconds

1. Click on the Windows Search Bar, type **PowerShell**, right-click it, and select **Run as Administrator**.
2. Copy **one** of the single-line installation commands from above.
3. Paste it directly into your terminal and hit **ENTER**. The automation matrix handles the rest.

## ✨ Core Features

* **Zero-Latency Toggling:** Instantly show, hide, or launch your applications without checking taskbars.
* **Smart Window Detection:** If an app is closed, it launches it. If it is open but buried under 10 windows, it pulls it directly to the absolute front of your focus. If it is already focused on top, it instantly minimizes it out of your way.
* **Non-Intrusive Engine Hooking:** Your Spacebar functions perfectly for normal typing, text entry, and system operations. No typing friction, no dropped inputs.
